# SDAD-Net 模块说明

本文件回答：SDAD-Net是什么、代码由哪些部分组成，以及如何与团队项目整合。

## 1. 方法定位

SDAD-Net：分阶段域对抗蒸馏网络  
Stage-wise Domain-Adversarial Distillation Network

面向运动想象脑电解码中的低表现者，采用三个相互配合的环节：

1. 时空特征融合：结合时序网络与CSP空间特征。
2. 教师—学生蒸馏：利用教师输出监督学生学习。
3. 后期域对抗：在分类能力形成后，加入高低表现组的域对抗约束。

部署推理使用学生模型。教师和域判别器用于训练，不必进入在线推理路径。

## 2. 在团队项目中的位置

| 代际 | 方法 | 代码整合原则 |
|---|---|---|
| 第一代 | 仅正常组训练，无蒸馏、无组间混合 | 采用ArceeXu整理版本 |
| 第二代 | 混合训练、时空融合与同步蒸馏 | 采用ArceeXu整理版本 |
| 第三代 | 时空融合与蒸馏基础上的后期DANN | 保留本模块实现与实验记录 |

GUI统一使用ArceeXu版本。

三代方法应各自保留配置与结果，不能因为模型名称相近而直接混用权重。

## 4. 数据接口

当前SDAD-Net实验采用：

- OpenBMI左右手运动想象二分类。
- 54名受试者。
- 11路EEG：FC1、FC2、FC5、FC6、C3、Cz、C4、CP1、CP2、CP5、CP6。
- 4秒片段、250 Hz采样率。
- session1训练与验证，session2测试。
- 固定25名低表现者名单。

接入团队代码前，必须核对：

- 通道数量及顺序。
- 采样率、滤波与片段长度。
- 标签编码。
- CSP与标准化器。
- 训练／验证／测试划分。
- 模型输入和输出接口。

未经核对，不直接加载另一版本的预处理资源或模型权重。

## 5. 后期配对实验设计

从相同预训练检查点构建两个分支：

- `control`：继续蒸馏，不加入域对抗。
- `group`：继续蒸馏，并加入高低组DANN。

配对比较保持相同的初始化来源、数据、批次构造规则、训练预算和检查点选择规则。

实验中为两个分支重新建立优化器，因此应描述为“从相同模型状态继续训练”，不等同于完整恢复原优化器训练轨迹。

验证集负责选择检查点，测试集负责评价固定检查点。

## 6. 当前结论

- 完整SDAD-Net相对于联合CSP+LDA具有明显性能提升。
- 后期DANN相对于匹配蒸馏对照的增益较小，且不同运行存在波动。
- 三次配对运行平均低表现组准确率为72.77%，平均达标人数为15/25。
- 无对抗对照对应为72.36%、13.67/25。
- 目前结果属于探索性证据，尚不能宣称稳定解决BCI低表现问题或具有临床疗效。

详细结果见 [experiment_index.md](experiment_index.md)。
